Getting started

DFiles is a two-pane file manager: a sidebar of Places and Bookmarks on the left, and the contents of the current folder on the right. Click any place or bookmark, or double-click a folder in the table, to navigate into it.

The folder you're viewing is watched for changes in the background, so files added, removed, or edited elsewhere show up automatically — no manual refresh needed (though a refresh button is there too).

Running DFiles

DFiles ships as a single runnable JAR, dfiles.jar (built with mvn package). It requires a Java 21 runtime (JRE or JDK) to be installed on your machine.

Windows

Open a Command Prompt or PowerShell in the folder containing dfiles.jar and run:

java -jar dfiles.jar

If Java is installed and associated with .jar files, double-clicking dfiles.jar in File Explorer also works. If you don't have Java yet, install it with winget install Microsoft.OpenJDK.21, or download an installer from adoptium.net.

Linux

From a terminal, in the folder containing the jar:

java -jar dfiles.jar

If you don't have Java yet, install it with your distribution's package manager, for example:

  • Debian / Ubuntu: sudo apt install default-jdk (or sudo apt install openjdk-21-jdk for a specific version)
  • Fedora: sudo dnf install java-21-openjdk
  • Arch Linux: sudo pacman -S jdk21-openjdk
DFiles is a graphical application and needs a working X11 or Wayland desktop session. If it fails to start with Unable to open DISPLAY, your shell's DISPLAY environment variable doesn't point at your actual graphical session — this is common on remote-desktop or multi-session setups, where a freshly opened terminal defaults to :0 while your real desktop session is :1 or higher. Check which display your desktop actually uses, then run export DISPLAY=:1 (adjusting the number) before launching DFiles, or add that line to your shell profile (~/.bashrc or ~/.zshrc) to fix it permanently.

macOS

From Terminal, in the folder containing the jar:

java -jar dfiles.jar

If you don't have Java 21 yet, the quickest way to install it is with Homebrew: brew install openjdk@21.

Places & bookmarks

The Places section lists your standard folders (Home, Desktop, Documents, Downloads, Music, Pictures, Videos, and Computer for the filesystem root). Folders that don't exist yet are created automatically so they always show up.

Click Add Folder… to bookmark any folder you use often; it appears under Bookmarks. Right-click a bookmark to remove it, or right-click any place or bookmark to see its Properties.

Drag the thin divider between Places and Bookmarks to resize them, and drag the divider between the sidebar and the file table to resize the whole sidebar.

File table

Click a column header (Name, Size, Type, Date Modified) to sort by it — click again to reverse the order. Your sort choice and whether hidden files are shown are remembered per folder.

  • The 👁 toggle shows or hides dotfiles / hidden entries.
  • The search box filters the current folder's contents live as you type.
  • Selecting a single file shows its Unix-style permission string in the status bar (e.g. -rw-r--r-- 1 user group 1024 jan 5 2026).
  • 📋 Copy File List copies the visible listing as tab-separated text to the clipboard.

File & folder actions

Right-click a file or folder (or empty space, for folder-level actions) for a context menu including:

  • Open / Open With Default Application — uses your OS's file associations
  • Cut, Copy, Paste, Rename, Delete — delete asks for confirmation first
  • New Folder / New File — also available as toolbar buttons
  • Copy Path — copies the full path to the clipboard
  • Properties — path, type, size (or item count for folders), modified date, and permissions

Archives

Double-clicking a zip, tar, tar.gz, tar.bz2, tar.xz, rar, or 7z file opens a listing of its contents instead of trying to run it. From there, or directly from the context menu:

  • Show Contents… — lists every entry in the archive
  • Extract Here — extracts directly into the current folder
  • Compress… (on any folder) — pick a name and a format (zip is always available; tar-based formats and 7z appear automatically if the matching command-line tool is installed on your system)

Text file tools

For recognized text files (txt, log, json, csv, xml, source code, and similar), the context menu adds:

  • View Head/Tail… — the first and last 100 lines, useful for skimming a large log without loading the whole thing
  • Find and Replace… — plain text or regular-expression search and replace with a live preview. The original file is never modified — saving writes a new name_v1.ext, name_v2.ext, and so on, numbered to avoid overwriting any previous version.

Git integration

When the current folder is inside a Git repository, the Git toolbar menu becomes active with Status, Pull, Push, Commit…, Log, and Init (to start a new repository). Output from each command appears in a panel at the bottom of the window.

Terminal & VS Code

  • Open Terminal (toolbar) or Open Terminal Here (context menu) — opens a terminal window at the current or selected folder
  • Open in VS Code — opens the folder (or a file's parent folder) in Visual Studio Code, if the code command is installed

AI-assisted scripts

The Scripts section in the sidebar lists bash scripts you've saved, stored in DFiles' own database rather than as files in the folder you're browsing. Click Add Script… to name a new one; right-click an existing script for Rename… or Delete.

Selecting or creating a script switches to the Script Development tab, a workspace split into three rows you can resize by dragging the dividers between them:

  1. AI Prompt — describe what you want in plain English and click Run Prompt to have an AI backend write the script for you.
  2. Script — the generated (or hand-written/edited) bash script. Click Save to store the prompt and script together.
  3. Terminal — click Run Script to execute the script against whatever folder you currently have open in the Files tab, with its combined output streamed here live. The output from the last run is saved automatically, so it's still there next time you open the script.

A dropdown next to Run Prompt chooses which AI backend writes the script:

  • OpenAI — DFiles reads the OPENAI_API_KEY environment variable at request time; it is never stored or logged. Set it before launching DFiles.
  • Local (Llamafile) — talks to a Llamafile server running on your own machine at http://localhost:8080, using the same OpenAI-compatible request format. No API key is needed, and nothing leaves your computer.
Scripts under test are written to a temporary file in <OS temp folder>/.dfiles/ and deleted again as soon as the run finishes.

Layout & language

The language selector supports English, Español, Français, Português, and Italiano — the whole interface updates immediately. On first launch, DFiles matches your operating system's language automatically if one of these is supported, otherwise it starts in English; once you pick a language yourself, that choice is remembered.

Where DFiles stores data

DFiles keeps a small SQLite database at ~/.dfiles/dfiles.sqlite for bookmarks, window and language preferences, per-folder sort settings, saved scripts (with their prompts and last run output), and a cache that lets folders you've visited before paint instantly. Application logs are written to ~/.dfiles/dfiles.log, and scripts under test run from a scratch folder at <OS temp folder>/.dfiles/.
