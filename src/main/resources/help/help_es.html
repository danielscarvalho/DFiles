Primeros pasos

DFiles es un gestor de archivos de dos paneles: una barra lateral con Lugares y Marcadores a la izquierda, y el contenido de la carpeta actual a la derecha. Haz clic en cualquier lugar o marcador, o haz doble clic en una carpeta de la tabla, para navegar a ella.

La carpeta que estás viendo se vigila en segundo plano, así que los archivos añadidos, eliminados o editados en otro lugar aparecen automáticamente — no hace falta actualizar a mano (aunque también hay un botón de actualizar).

Ejecutar DFiles

DFiles se distribuye como un único JAR ejecutable, dfiles.jar (compilado con mvn package). Requiere tener instalado un entorno de ejecución Java 21 (JRE o JDK).

Windows

Abre el Símbolo del sistema o PowerShell en la carpeta que contiene dfiles.jar y ejecuta:

java -jar dfiles.jar

Si Java está instalado y asociado a los archivos .jar, hacer doble clic en dfiles.jar desde el Explorador de archivos también funciona. Si aún no tienes Java, instálalo con winget install Microsoft.OpenJDK.21, o descarga un instalador desde adoptium.net.

Linux

Desde una terminal, en la carpeta que contiene el jar:

java -jar dfiles.jar

Si aún no tienes Java, instálalo con el gestor de paquetes de tu distribución, por ejemplo:

  • Debian / Ubuntu: sudo apt install default-jdk (o sudo apt install openjdk-21-jdk para una versión específica)
  • Fedora: sudo dnf install java-21-openjdk
  • Arch Linux: sudo pacman -S jdk21-openjdk
DFiles es una aplicación gráfica y necesita una sesión de escritorio X11 o Wayland en funcionamiento. Si falla al iniciar con el error Unable to open DISPLAY, la variable de entorno DISPLAY de tu shell no apunta a tu sesión gráfica real — esto es habitual en configuraciones de escritorio remoto o con varias sesiones, donde una terminal recién abierta usa por defecto :0 mientras tu sesión de escritorio real es :1 o superior. Comprueba qué pantalla usa realmente tu escritorio y ejecuta export DISPLAY=:1 (ajustando el número) antes de iniciar DFiles, o añade esa línea a tu perfil de shell (~/.bashrc o ~/.zshrc) para solucionarlo de forma permanente.

macOS

Desde Terminal, en la carpeta que contiene el jar:

java -jar dfiles.jar

Si aún no tienes Java 21, la forma más rápida de instalarlo es con Homebrew: brew install openjdk@21.

Lugares y marcadores

La sección Lugares muestra tus carpetas estándar (Inicio, Escritorio, Documentos, Descargas, Música, Imágenes, Vídeos y Equipo para la raíz del sistema de archivos). Las carpetas que aún no existen se crean automáticamente para que siempre aparezcan.

Haz clic en Añadir carpeta… para marcar cualquier carpeta que uses a menudo; aparecerá bajo Marcadores. Haz clic derecho en un marcador para eliminarlo, o en cualquier lugar o marcador para ver sus Propiedades.

Arrastra el divisor entre Lugares y Marcadores para redimensionarlos, y el divisor entre el panel lateral y la tabla de archivos para redimensionar todo el panel lateral.

Tabla de archivos

Haz clic en el encabezado de una columna (Nombre, Tamaño, Tipo, Fecha de modificación) para ordenar por ella — vuelve a hacer clic para invertir el orden. Tu elección de orden y si se muestran los archivos ocultos se recuerdan por carpeta.

  • El interruptor 👁 muestra u oculta los archivos ocultos.
  • El cuadro de búsqueda filtra el contenido de la carpeta actual en tiempo real mientras escribes.
  • Seleccionar un único archivo muestra su cadena de permisos estilo Unix en la barra de estado (p. ej. -rw-r--r-- 1 usuario grupo 1024 ene 5 2026).
  • 📋 Copiar lista de archivos copia el listado visible como texto separado por tabulaciones al portapapeles.

Acciones sobre archivos y carpetas

Haz clic derecho en un archivo o carpeta (o en un espacio vacío, para acciones a nivel de carpeta) para ver un menú contextual que incluye:

  • Abrir / Abrir con la aplicación predeterminada — usa las asociaciones de archivo de tu sistema
  • Cortar, Copiar, Pegar, Renombrar, Eliminar — eliminar pide confirmación primero
  • Nueva carpeta / Nuevo archivo — también disponibles como botones de la barra de herramientas
  • Copiar ruta — copia la ruta completa al portapapeles
  • Propiedades — ruta, tipo, tamaño (o número de elementos para carpetas), fecha de modificación y permisos

Archivos comprimidos

Al hacer doble clic en un archivo zip, tar, tar.gz, tar.bz2, tar.xz, rar o 7z se abre un listado de su contenido en lugar de intentar ejecutarlo. Desde allí, o directamente desde el menú contextual:

  • Ver contenido… — lista todas las entradas del archivo
  • Extraer aquí — extrae directamente en la carpeta actual
  • Comprimir… (en cualquier carpeta) — elige un nombre y un formato (zip siempre está disponible; los formatos basados en tar y 7z aparecen automáticamente si la herramienta de línea de comandos correspondiente está instalada en tu sistema)

Herramientas de texto

Para archivos de texto reconocidos (txt, log, json, csv, xml, código fuente y similares), el menú contextual añade:

  • Ver inicio/final… — las primeras y últimas 100 líneas, útil para revisar un registro grande sin cargarlo entero
  • Buscar y reemplazar… — búsqueda y reemplazo de texto plano o expresión regular con vista previa en vivo. El archivo original nunca se modifica — al guardar se crea un nuevo nombre_v1.ext, nombre_v2.ext, y así sucesivamente, numerados para no sobrescribir ninguna versión anterior.

Integración con Git

Cuando la carpeta actual está dentro de un repositorio Git, el menú Git de la barra de herramientas se activa con Estado, Actualizar (Pull), Enviar (Push), Confirmar…, Historial e Inicializar (para crear un nuevo repositorio). La salida de cada comando aparece en un panel en la parte inferior de la ventana.

Terminal y VS Code

  • Abrir terminal (barra de herramientas) o Abrir terminal aquí (menú contextual) — abre una ventana de terminal en la carpeta actual o seleccionada
  • Abrir en VS Code — abre la carpeta (o la carpeta contenedora de un archivo) en Visual Studio Code, si el comando code está instalado

Scripts asistidos por IA

La sección Scripts del panel lateral lista los scripts bash que has guardado, almacenados en la propia base de datos de DFiles y no como archivos en la carpeta que estás explorando. Haz clic en Añadir script… para nombrar uno nuevo; haz clic derecho en un script existente para Renombrar… o Eliminar.

Al seleccionar o crear un script se cambia a la pestaña Desarrollo de scripts, un espacio de trabajo dividido en tres filas que puedes redimensionar arrastrando los divisores entre ellas:

  1. Instrucción para la IA — describe lo que quieres en lenguaje natural y haz clic en Ejecutar instrucción para que un backend de IA escriba el script por ti.
  2. Script — el script bash generado (o escrito/editado a mano). Haz clic en Guardar para almacenar juntos la instrucción y el script.
  3. Terminal — haz clic en Ejecutar script para ejecutarlo contra la carpeta que tengas abierta en la pestaña Archivos, con su salida combinada transmitida aquí en vivo. La salida de la última ejecución se guarda automáticamente, así que sigue ahí la próxima vez que abras el script.

Un menú desplegable junto a Ejecutar instrucción elige qué backend de IA escribe el script:

  • OpenAI — DFiles lee la variable de entorno OPENAI_API_KEY en el momento de la solicitud; nunca se almacena ni se registra. Configúrala antes de iniciar DFiles.
  • Local (Llamafile) — se comunica con un servidor Llamafile ejecutándose en tu propia máquina en http://localhost:8080, usando el mismo formato de solicitud compatible con OpenAI. No necesita clave de API y nada sale de tu ordenador.
Los scripts en prueba se escriben en un archivo temporal en <carpeta temporal del sistema>/.dfiles/ y se eliminan de nuevo en cuanto termina la ejecución.

Convertir datos

El botón ⇄ Convertir de la barra de herramientas (o Convertir… en el menú contextual de un archivo compatible) abre un diálogo que transforma datos tabulares de un formato a otro, inspirado en convertcsv.com.

Formatos de entrada admitidos:

  • CSV y TSV — separados por comas o tabulaciones, con la primera fila como encabezado
  • JSON — un array de objetos planos (o un único objeto, tratado como una fila); las columnas son la unión de las claves de todos los objetos, en el orden en que aparecen
  • XML — elementos repetidos bajo la raíz (la etiqueta más común entre los hijos directos de la raíz se lee como una fila por cada aparición); los elementos hijos de cada fila se convierten en columnas
  • Tabla Markdown — una tabla estándar con pipes | --- | --- |
  • YAML — una lista plana de mapeos planos (- name: Alice /   age: 30); no se admiten estructuras anidadas, estilo flow ni archivos multi-documento
  • Excel (.xlsx) — la primera hoja, con la primera fila como encabezado

Un único campo Archivo local o URL acepta una ruta local (o una elegida con Examinar…) o una dirección web; déjalo vacío y el cuadro de texto grande de abajo funciona como un área para pegar texto normal. Al rellenar el campo, ese mismo cuadro se vuelve de solo lectura y carga una vista previa de muestra del contenido del archivo o la URL — Convertir siempre vuelve a leer la fuente completa desde cero en lugar de reutilizar la muestra. Una elección de codificación de caracteres (UTF-8, UTF-16, Latin-1, US-ASCII, Windows-1252) se aplica a los formatos basados en texto, y el formato de entrada puede dejarse en Auto-detect, que analiza el contenido, o fijarse explícitamente.

El formato de salida puede ser SQL, CSV, TSV, JSON, XML, una tabla HTML, una tabla Markdown, YAML o Excel. Para SQL, un selector de dialecto SQL elige la base de datos destino — SQLite, MySQL, PostgreSQL, Oracle o Microsoft SQL Server — ya que difieren bastante entre sí: nombres de tipos de columna, cómo iniciar una transacción, y cómo eliminar y recrear una tabla de forma segura (ninguno admite realmente la sintaxis literal CREATE OR REPLACE TABLE, así que cada dialecto genera su propio modismo correcto — para Oracle es un pequeño bloque PL/SQL, ya que Oracle no tiene DROP TABLE IF EXISTS). Todo el conjunto de datos se convierte en un único INSERT envuelto en una transacción cuando la base de datos destino lo permite; Microsoft SQL Server limita un único INSERT ... VALUES a 1000 filas, así que los resultados más grandes se dividen en varios, y Oracle no tiene ninguna lista VALUES multifila, así que se reescribe como INSERT ALL. Los tipos de columna se infieren a partir de los datos, y el paso CREATE TABLE (en la forma que necesite el dialecto elegido) se puede incluir o excluir, para insertar en una tabla que ya existe.

El origen — texto pegado, un archivo elegido o una URL descargada — solo se lee. Los resultados se escriben en un archivo completamente nuevo que eliges con Guardar como…; elegir exactamente el archivo de origen como destino de guardado se rechaza.

Para una corrección rápida, haz clic derecho en cualquier archivo .csv para Convertir CSV latino a inglés…: transforma un CSV de estilo europeo continental (; como separador de campos, , como marca decimal — p. ej. 1.234,56) en el equivalente de estilo inglés (separadores ,, decimales . — 1234.56), guardando el resultado como <nombre>_en.csv junto al original sin tocarlo. Solo se reinterpretan las celdas que parecen un número correctamente formateado — el texto normal (incluida una coma literal dentro de un campo entre comillas) se deja exactamente igual.

Diseño e idioma

El selector de idioma admite English, Español, Français, Português e Italiano — toda la interfaz se actualiza al instante. En el primer inicio, DFiles hace coincidir automáticamente el idioma de tu sistema operativo si es uno de estos, y si no, empieza en inglés; en cuanto eliges un idioma tú mismo, esa elección se recuerda.

Dónde guarda datos DFiles

DFiles mantiene una pequeña base de datos SQLite en ~/.dfiles/dfiles.sqlite para marcadores, preferencias de ventana e idioma, ajustes de orden por carpeta, scripts guardados (con sus instrucciones y la salida de la última ejecución), y una caché que permite que las carpetas ya visitadas se pinten al instante. Los registros de la aplicación se escriben en ~/.dfiles/dfiles.log, y los scripts en prueba se ejecutan desde una carpeta temporal en <carpeta temporal del sistema>/.dfiles/.
