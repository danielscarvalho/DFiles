Premiers pas

DFiles est un gestionnaire de fichiers à deux volets : une barre latérale avec Emplacements et Favoris à gauche, et le contenu du dossier actuel à droite. Cliquez sur un emplacement ou un favori, ou double-cliquez sur un dossier dans le tableau, pour y accéder.

Le dossier que vous consultez est surveillé en arrière-plan, donc les fichiers ajoutés, supprimés ou modifiés ailleurs apparaissent automatiquement — pas besoin d'actualiser manuellement (même s'il existe aussi un bouton d'actualisation).

Lancer DFiles

DFiles est distribué sous la forme d'un unique fichier JAR exécutable, dfiles.jar (compilé avec mvn package). Un environnement d'exécution Java 21 (JRE ou JDK) doit être installé sur votre machine.

Windows

Ouvrez une invite de commandes ou PowerShell dans le dossier contenant dfiles.jar et exécutez :

java -jar dfiles.jar

Si Java est installé et associé aux fichiers .jar, un double-clic sur dfiles.jar dans l'Explorateur de fichiers fonctionne également.

Linux

Depuis un terminal, dans le dossier contenant le jar :

java -jar dfiles.jar

DFiles est une application graphique et a besoin d'une session de bureau X11 ou Wayland fonctionnelle. S'il ne démarre pas et affiche l'erreur Unable to open DISPLAY, la variable d'environnement DISPLAY de votre shell ne pointe pas vers votre véritable session graphique — un cas fréquent sur les configurations de bureau à distance ou multi-sessions, où un terminal fraîchement ouvert utilise par défaut :0 alors que votre session de bureau réelle est :1 ou supérieure. Vérifiez quel affichage votre bureau utilise réellement, puis exécutez export DISPLAY=:1 (en ajustant le numéro) avant de lancer DFiles, ou ajoutez cette ligne à votre profil shell (~/.bashrc ou ~/.zshrc) pour une correction permanente.

macOS

Depuis Terminal, dans le dossier contenant le jar :

java -jar dfiles.jar

Si vous n'avez pas encore Java 21, le moyen le plus rapide de l'installer est Homebrew : brew install openjdk@21.

Emplacements et favoris

La section Emplacements affiche vos dossiers standards (Accueil, Bureau, Documents, Téléchargements, Musique, Images, Vidéos et Poste de travail pour la racine du système de fichiers). Les dossiers qui n'existent pas encore sont créés automatiquement afin qu'ils apparaissent toujours.

Cliquez sur Ajouter un dossier… pour mettre en favori tout dossier que vous utilisez souvent ; il apparaîtra sous Favoris. Faites un clic droit sur un favori pour le supprimer, ou sur un emplacement ou favori pour voir ses Propriétés.

Faites glisser le séparateur entre Emplacements et Favoris pour les redimensionner, et celui entre le panneau latéral et le tableau des fichiers pour redimensionner tout le panneau latéral.

Tableau des fichiers

Cliquez sur l'en-tête d'une colonne (Nom, Taille, Type, Date de modification) pour trier selon celle-ci — cliquez à nouveau pour inverser l'ordre. Votre choix de tri et l'affichage ou non des fichiers cachés sont mémorisés par dossier.

  • L'interrupteur 👁 affiche ou masque les fichiers cachés.
  • Le champ de recherche filtre le contenu du dossier actuel en temps réel pendant la saisie.
  • Sélectionner un seul fichier affiche sa chaîne de permissions de type Unix dans la barre d'état (par ex. -rw-r--r-- 1 utilisateur groupe 1024 jan 5 2026).
  • 📋 Copier la liste des fichiers copie le contenu affiché sous forme de texte séparé par tabulations dans le presse-papiers.

Actions sur fichiers et dossiers

Faites un clic droit sur un fichier ou un dossier (ou sur un espace vide, pour des actions au niveau du dossier) pour afficher un menu contextuel comprenant :

  • Ouvrir / Ouvrir avec l'application par défaut — utilise les associations de fichiers de votre système
  • Couper, Copier, Coller, Renommer, Supprimer — la suppression demande d'abord confirmation
  • Nouveau dossier / Nouveau fichier — également disponibles comme boutons de la barre d'outils
  • Copier le chemin — copie le chemin complet dans le presse-papiers
  • Propriétés — chemin, type, taille (ou nombre d'éléments pour les dossiers), date de modification et permissions

Archives

Double-cliquer sur un fichier zip, tar, tar.gz, tar.bz2, tar.xz, rar ou 7z ouvre un aperçu de son contenu au lieu de tenter de l'exécuter. À partir de là, ou directement depuis le menu contextuel :

  • Voir le contenu… — liste toutes les entrées de l'archive
  • Extraire ici — extrait directement dans le dossier actuel
  • Compresser… (sur n'importe quel dossier) — choisissez un nom et un format (zip toujours disponible ; les formats basés sur tar et 7z apparaissent automatiquement si l'outil en ligne de commande correspondant est installé sur votre système)

Outils de texte

Pour les fichiers texte reconnus (txt, log, json, csv, xml, code source et similaires), le menu contextuel ajoute :

  • Voir début/fin… — les 100 premières et dernières lignes, utile pour parcourir un gros journal sans le charger entièrement
  • Rechercher et remplacer… — recherche et remplacement en texte brut ou expression régulière avec aperçu en direct. Le fichier original n'est jamais modifié — enregistrer crée un nouveau nom_v1.ext, nom_v2.ext, et ainsi de suite, numérotés pour ne jamais écraser une version précédente.

Intégration Git

Lorsque le dossier actuel se trouve dans un dépôt Git, le menu Git de la barre d'outils s'active avec Statut, Tirer (Pull), Pousser (Push), Valider…, Historique et Initialiser (pour créer un nouveau dépôt). La sortie de chaque commande apparaît dans un panneau en bas de la fenêtre.

Terminal et VS Code

  • Ouvrir un terminal (barre d'outils) ou Ouvrir un terminal ici (menu contextuel) — ouvre une fenêtre de terminal dans le dossier actuel ou sélectionné
  • Ouvrir dans VS Code — ouvre le dossier (ou le dossier parent d'un fichier) dans Visual Studio Code, si la commande code est installée

Scripts assistés par IA

La section Scripts du panneau latéral liste les scripts bash que vous avez enregistrés, stockés dans la base de données de DFiles elle-même et non comme des fichiers dans le dossier que vous parcourez. Cliquez sur Ajouter un script… pour en nommer un nouveau ; faites un clic droit sur un script existant pour le Renommer… ou le Supprimer.

Sélectionner ou créer un script bascule vers l'onglet Développement de script, un espace de travail divisé en trois rangées que vous pouvez redimensionner en faisant glisser les séparateurs entre elles :

  1. Invite IA — décrivez ce que vous voulez en langage naturel et cliquez sur Exécuter l'invite pour qu'un backend IA écrive le script à votre place.
  2. Script — le script bash généré (ou écrit/modifié manuellement). Cliquez sur Enregistrer pour stocker ensemble l'invite et le script.
  3. Terminal — cliquez sur Exécuter le script pour l'exécuter sur le dossier ouvert dans l'onglet Fichiers, avec sa sortie combinée diffusée ici en direct. La sortie de la dernière exécution est enregistrée automatiquement, donc elle reste disponible la prochaine fois que vous ouvrez le script.

Un menu déroulant à côté de Exécuter l'invite choisit quel backend IA écrit le script :

  • OpenAI — DFiles lit la variable d'environnement OPENAI_API_KEY au moment de la requête ; elle n'est jamais stockée ni journalisée. Définissez-la avant de démarrer DFiles.
  • Local (Llamafile) — communique avec un serveur Llamafile exécuté sur votre propre machine à l'adresse http://localhost:8080, en utilisant le même format de requête compatible OpenAI. Aucune clé API requise, et rien ne quitte votre ordinateur.
Les scripts en cours de test sont écrits dans un fichier temporaire sous <dossier temporaire du système>/.dfiles/ et supprimés dès la fin de l'exécution.

Disposition et langue

Le sélecteur de langue prend en charge l'anglais, l'espagnol, le français et le portugais — toute l'interface se met à jour instantanément. Au premier démarrage, DFiles fait automatiquement correspondre la langue de votre système d'exploitation si elle figure parmi celles-ci, sinon il démarre en anglais ; dès que vous choisissez vous-même une langue, ce choix est mémorisé.

Où DFiles stocke ses données

DFiles conserve une petite base de données SQLite dans ~/.dfiles/dfiles.sqlite pour les favoris, les préférences de fenêtre et de langue, les paramètres de tri par dossier, les scripts enregistrés (avec leurs invites et la sortie de la dernière exécution), et un cache qui permet d'afficher instantanément les dossiers déjà visités. Les journaux de l'application sont écrits dans ~/.dfiles/dfiles.log, et les scripts en cours de test s'exécutent depuis un dossier temporaire sous <dossier temporaire du système>/.dfiles/.
