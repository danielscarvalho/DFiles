Per iniziare

DFiles è un file manager a due pannelli: una barra laterale con Risorse e Preferiti a sinistra, e il contenuto della cartella corrente a destra. Fai clic su una risorsa o un preferito, oppure doppio clic su una cartella nella tabella, per navigarci dentro.

La cartella che stai visualizzando viene monitorata in background, quindi i file aggiunti, rimossi o modificati altrove compaiono automaticamente — non serve aggiornare manualmente (anche se è comunque presente un pulsante di aggiornamento).

Avviare DFiles

DFiles viene distribuito come un unico JAR eseguibile, dfiles.jar (compilato con mvn package). È necessario avere installato un runtime Java 21 (JRE o JDK) sulla propria macchina.

Windows

Apri il Prompt dei comandi o PowerShell nella cartella che contiene dfiles.jar ed esegui:

java -jar dfiles.jar

Se Java è installato ed è associato ai file .jar, funziona anche il doppio clic su dfiles.jar in Esplora file. Se non hai ancora Java, installalo con winget install Microsoft.OpenJDK.21, oppure scarica un installer da adoptium.net.

Linux

Da un terminale, nella cartella che contiene il jar:

java -jar dfiles.jar

Se non hai ancora Java, installalo con il gestore di pacchetti della tua distribuzione, ad esempio:

  • Debian / Ubuntu: sudo apt install default-jdk (oppure sudo apt install openjdk-21-jdk per una versione specifica)
  • Fedora: sudo dnf install java-21-openjdk
  • Arch Linux: sudo pacman -S jdk21-openjdk
DFiles è un'applicazione grafica e richiede una sessione desktop X11 o Wayland funzionante. Se non si avvia e mostra l'errore Unable to open DISPLAY, la variabile d'ambiente DISPLAY della tua shell non punta alla tua vera sessione grafica — è un caso comune nelle configurazioni desktop remote o multi-sessione, dove un terminale appena aperto usa per impostazione predefinita :0 mentre la tua sessione desktop reale è :1 o superiore. Verifica quale display usa realmente il tuo desktop, poi esegui export DISPLAY=:1 (adattando il numero) prima di avviare DFiles, oppure aggiungi quella riga al tuo profilo shell (~/.bashrc o ~/.zshrc) per risolverlo in modo permanente.

macOS

Da Terminale, nella cartella che contiene il jar:

java -jar dfiles.jar

Se non hai ancora Java 21, il modo più rapido per installarlo è con Homebrew: brew install openjdk@21.

Requisiti e strumenti opzionali

Per eseguire DFiles è necessario solo un runtime Java 21. Tutto il resto elencato di seguito è opzionale, e serve solo se utilizzi la funzionalità corrispondente:

StrumentoNecessario per
Java 21 (JRE/JDK)Eseguire DFiles — obbligatorio
GitIl menu Git della barra degli strumenti (Stato, Pull, Push, Commit, Cronologia, Inizializza) — DFiles richiama il comando git esternamente, quindi deve essere installato e presente nel tuo PATH
OPENAI_API_KEYIl backend OpenAI per gli script assistiti dall'IA — imposta questa variabile d'ambiente prima di avviare DFiles

Risorse e preferiti

La sezione Risorse elenca le tue cartelle standard (Home, Scrivania, Documenti, Download, Musica, Immagini, Video e Computer per la radice del file system). Le cartelle che non esistono ancora vengono create automaticamente, così compaiono sempre.

Fai clic su Aggiungi cartella… per aggiungere ai preferiti qualsiasi cartella usi spesso; comparirà sotto Preferiti. Fai clic destro su un preferito per rimuoverlo, o su qualsiasi risorsa o preferito per vederne le Proprietà.

Trascina il sottile divisore tra Risorse e Preferiti per ridimensionarli, e il divisore tra la barra laterale e la tabella dei file per ridimensionare l'intera barra laterale.

Tabella dei file

Fai clic sull'intestazione di una colonna (Nome, Dimensione, Tipo, Data di modifica) per ordinare in base a essa — fai clic di nuovo per invertire l'ordine. La tua scelta di ordinamento e se i file nascosti sono mostrati vengono ricordati per ogni cartella.

  • L'interruttore 👁 mostra o nasconde i file nascosti.
  • Il campo di ricerca filtra il contenuto della cartella corrente in tempo reale mentre digiti.
  • Selezionando un singolo file viene mostrata la sua stringa di permessi in stile Unix nella barra di stato (ad es. -rw-r--r-- 1 utente gruppo 1024 gen 5 2026).
  • 📋 Copia elenco file copia l'elenco visibile come testo separato da tabulazioni negli appunti.

Azioni su file e cartelle

Fai clic destro su un file o una cartella (o su uno spazio vuoto, per azioni a livello di cartella) per vedere un menu contestuale che include:

  • Apri / Apri con l'applicazione predefinita — usa le associazioni file del tuo sistema operativo
  • Taglia, Copia, Incolla, Rinomina, Elimina — l'eliminazione chiede prima conferma
  • Nuova cartella / Nuovo file — disponibili anche come pulsanti della barra degli strumenti
  • Copia percorso — copia il percorso completo negli appunti
  • Proprietà — percorso, tipo, dimensione (o numero di elementi per le cartelle), data di modifica e permessi

Archivi

Il doppio clic su un file zip, tar, tar.gz, tar.bz2, tar.xz, rar o 7z apre un elenco del suo contenuto invece di provare a eseguirlo. Da lì, o direttamente dal menu contestuale:

  • Visualizza contenuto… — elenca ogni voce dell'archivio
  • Estrai qui — estrae direttamente nella cartella corrente
  • Comprimi… (su qualsiasi cartella) — scegli un nome e un formato (zip è sempre disponibile; i formati basati su tar e 7z compaiono automaticamente se lo strumento a riga di comando corrispondente è installato sul tuo sistema)

Strumenti per file di testo

Per i file di testo riconosciuti (txt, log, json, csv, xml, codice sorgente e simili), il menu contestuale aggiunge:

  • Visualizza inizio/fine… — le prime e le ultime 100 righe, utile per scorrere un log di grandi dimensioni senza caricarlo per intero
  • Trova e sostituisci… — ricerca e sostituzione in testo semplice o espressione regolare con anteprima dal vivo. Il file originale non viene mai modificato — il salvataggio scrive un nuovo nome_v1.ext, nome_v2.ext e così via, numerati per evitare di sovrascrivere versioni precedenti.

Integrazione con Git

Quando la cartella corrente si trova all'interno di un repository Git, il menu Git della barra degli strumenti diventa attivo con Stato, Pull, Push, Commit…, Cronologia e Inizializza (per avviare un nuovo repository). L'output di ogni comando compare in un pannello nella parte inferiore della finestra.

Terminale e VS Code

  • Apri terminale (barra degli strumenti) o Apri terminale qui (menu contestuale) — apre una finestra di terminale nella cartella corrente o selezionata
  • Apri in VS Code — apre la cartella (o la cartella superiore di un file) in Visual Studio Code, se il comando code è installato

Script assistiti dall'IA

La sezione Script nella barra laterale elenca gli script bash che hai salvato, memorizzati nel database interno di DFiles anziché come file nella cartella che stai esplorando. Fai clic su Aggiungi script… per darne un nome a uno nuovo; fai clic destro su uno script esistente per Rinomina… o Elimina.

Selezionare o creare uno script passa alla scheda Sviluppo script, un'area di lavoro divisa in tre righe che puoi ridimensionare trascinando i divisori tra di esse:

  1. Prompt IA — descrivi cosa vuoi in linguaggio naturale e fai clic su Esegui prompt per far scrivere lo script da un backend IA al posto tuo.
  2. Script — lo script bash generato (o scritto/modificato manualmente). Fai clic su Salva per memorizzare insieme prompt e script.
  3. Terminale — fai clic su Esegui script per eseguirlo sulla cartella che hai attualmente aperta nella scheda File, con il suo output combinato trasmesso qui in diretta. L'output dell'ultima esecuzione viene salvato automaticamente, quindi sarà ancora lì la prossima volta che apri lo script.

Un menu a discesa accanto a Esegui prompt sceglie quale backend IA scrive lo script:

  • OpenAI — DFiles legge la variabile d'ambiente OPENAI_API_KEY al momento della richiesta; non viene mai memorizzata né registrata nei log. Impostala prima di avviare DFiles.
  • Locale (Llamafile) — comunica con un server Llamafile in esecuzione sulla tua stessa macchina all'indirizzo http://localhost:8080, usando lo stesso formato di richiesta compatibile con OpenAI. Non serve alcuna chiave API, e nulla lascia il tuo computer.
Gli script in prova vengono scritti in un file temporaneo in <cartella temporanea del sistema>/.dfiles/ ed eliminati non appena l'esecuzione termina.

Layout e lingua

Il selettore di lingua supporta inglese, spagnolo, francese, portoghese e italiano — l'intera interfaccia si aggiorna immediatamente. Al primo avvio, DFiles fa corrispondere automaticamente la lingua del tuo sistema operativo se è una di queste, altrimenti parte in inglese; non appena scegli tu stesso una lingua, quella scelta viene ricordata.

Dove DFiles salva i dati

DFiles mantiene un piccolo database SQLite in ~/.dfiles/dfiles.sqlite per preferiti, preferenze di finestra e lingua, impostazioni di ordinamento per cartella, script salvati (con i relativi prompt e l'output dell'ultima esecuzione), e una cache che permette di visualizzare istantaneamente le cartelle già visitate. I log dell'applicazione vengono scritti in ~/.dfiles/dfiles.log, e gli script in prova vengono eseguiti da una cartella temporanea in <cartella temporanea del sistema>/.dfiles/.
